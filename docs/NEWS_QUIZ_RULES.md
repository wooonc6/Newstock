# 종목별 과거 뉴스 퀴즈 기준

## 목적

`최근 읽을 뉴스`와 `종목별 과거 뉴스 퀴즈`는 서로 다른 데이터 흐름으로 운영한다.

- 최근 읽을 뉴스: 네이버 뉴스 API의 최신 기사, 읽기 전용
- 종목별 뉴스 퀴즈: Supabase `curated_news`에 검증해 저장한 과거 기사, 상승·하락 퀴즈용
- 종목별 목표 데이터: 약 15개 기사

## 문제 구성

한 기사를 가지고 1·3·6개월 후를 연속으로 묻지 않는다. 기사 한 건이 문제 한 개이며, 현재 기준 약 1·3·6개월 전과 12개월 이상 전의 서로 다른 기사를 최대 15개까지 사용한다. 14일이 지나지 않은 최신 기사는 읽기용 뉴스와 혼동하지 않도록 퀴즈에서 제외한다.

## 정답 판정

1. 기준가: 기사 발표 직전 거래일 종가
2. 비교가: 기사 발표일을 제외하고 이후 세 번째 거래일 종가
3. 변동률: `(비교가 - 기준가) / 기준가 × 100`
4. 변동률이 0 이상이면 상승, 0 미만이면 하락
5. 절대 변동률이 0.5% 미만인 기사는 방향성이 약하므로 퀴즈에서 제외

주말이나 휴장일은 거래일 수에 포함하지 않는다. 기사 날짜에 장이 열렸더라도 기사 게시 시간을 알 수 없으므로 기사 당일 종가는 비교 대상에서 제외한다.

## 코드 경로

- 공통 판정 로직: `src/lib/newsImpact.ts`
- 종목별 최대 15문제 피드: `src/app/api/learning/quiz-feed/[ticker]/route.ts`
- 서버 재채점·보상: `src/app/api/quiz/submit-v2/route.ts`
- 퀴즈 화면: `src/app/(main)/quiz/[stock]/QuizClient.tsx`

클라이언트가 보낸 정답 방향이나 코인 액수는 신뢰하지 않는다. 제출 시 서버가 뉴스 날짜와 Yahoo Finance 종가를 다시 확인하고, 뉴스 시기 구간에 따라 보상을 결정한다.

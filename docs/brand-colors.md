# Newstock 브랜드 컬러

## 로고 사용 색상

| 이름 | HEX | 용도 |
|------|-----|------|
| Logo Green | `#037A67` | N 심볼 메인 색상 |
| Logo Green Light | `#0D8D74` | N 심볼 하이라이트 |
| Logo Navy | `#1F2A33` | 문서 아이콘, "stock" 텍스트 |
| Logo Navy Dark | `#212C35` | 문서 아이콘 보조 |
| Logo Gray | `#555A5F` | 문서 텍스트 줄 |
| Logo White | `#FAFAFA` | 원형 강조 요소 |

## 사이트 CSS 변수 (globals.css)

| 변수 | HEX | 용도 |
|------|-----|------|
| `--accent` | `#00A878` | 버튼, 링크, 강조 (하나고 Green) |
| `--accent2` | `#1A3A5C` | 보조 강조 (하나고 Dark Blue) |
| `--text` | `#404040` | 본문 텍스트 (하나고 Gray K85) |
| `--text-muted` | `#888888` | 보조 텍스트 |
| `--text-dim` | `#555555` | 흐린 텍스트 |
| `--bg` | `#F5F7FA` | 페이지 배경 |
| `--surface` | `#FFFFFF` | 카드 배경 |
| `--surface2` | `#F0F2F5` | 입력창, 보조 배경 |
| `--border` | `rgba(0,0,0,0.09)` | 테두리 |
| `--warn` / `--coin` | `#B8A030` | 경고, 코인 (하나고 Gold) |
| `--danger` | `#EF4444` | 오류, 위험 |
| `--purple` | `#D43A8A` | 배지 강조 (하나고 Magenta) |

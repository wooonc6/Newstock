# Newstock 투자 학습 시스템 v1

## 목표

Newstock의 분석 기능을 단순 점수판이 아니라 `뉴스 → 개념 → 퀴즈 → 진단 → 학습 → 모의투자`로 이어지는 학습 순환 구조로 만든다.

별도 AI API는 사용하지 않는다. 모든 결과는 사용자의 퀴즈 기록, 뉴스 카테고리, 종목 산업군과 사전에 정의된 규칙으로 계산한다.

## 핵심 원칙

1. 사용자가 직접 선택하지 않은 분야를 고정 성향으로 단정하지 않는다.
2. 문항이 없는 영역은 0점 약점으로 처리하지 않고 `측정 전`으로 표시한다.
3. 큰 역량 영역보다 실제 오답이 누적된 세부 개념을 먼저 설명한다.
4. 추천 행동을 퀴즈 하나로 몰지 않고 개념, 뉴스, 퀴즈, 모의투자로 분산한다.
5. 현재 데이터로 분류할 수 없는 기록은 억지로 네 영역에 균등 배정하지 않는다.

## 개념 체계

### 기업 분석
- 실적: 매출, 영업이익, 순이익, EPS
- 재무: 자산, 부채, 현금흐름, ROE
- 가치평가: PER, PBR, 시가총액
- 기업 이벤트: 배당, 증자, 자사주, M&A

### 산업 분석
- 산업 구조: 수요와 공급, 경쟁사, 시장점유율, 공급망
- 산업 흐름: 업황, 산업 사이클
- 주요 업종: 반도체, 자동차, 2차전지, 바이오, 조선, 방산, 금융, 에너지, 플랫폼, 게임, 건설

### 경제 분석
- 통화와 금리: 기준금리, 시장금리, 채권금리, 연준, 한국은행
- 물가와 경기: 물가, CPI, GDP, 경기침체, 경기회복, 고용
- 대외 변수: 환율, 달러, 수출, 무역, 원유, 원자재

### 투자 판단
- 위험 관리: 분산투자, 변동성, 손절, 익절
- 시간 관점: 장기투자, 단기투자
- 시장 심리: FOMO, 군중심리, 과열
- 뉴스 판단: 상승 요인, 하락 요인, 불확실성, 거래량

## 진단 규칙

- 전체 기록 70%, 최근 10문항 30%
- 1~2문항: 데이터 부족
- 3~5문항: 데이터 보통
- 6문항 이상: 데이터 충분
- 전체 8문항 미만이면 종합 진단 준비 중
- 문항 수가 0인 영역은 점수 대신 `측정 전`
- 약점은 문항이 존재하는 영역 중 점수가 가장 낮은 영역으로 선정
- 세부 약점은 해당 영역에서 오답 수가 가장 많은 개념으로 선정

## 추천 미션 구조

1. 개념 도감에서 취약 개념 읽기
2. 대시보드에서 해당 개념이 실제 뉴스에 어떻게 나타나는지 확인
3. 퀴즈에서 뉴스 해석을 점검
4. 모의투자에서 종목의 기회와 위험을 함께 기록

추천 미션은 진행률을 가장하지 않는다. 별도 완료 기록 테이블이 생기기 전에는 행동 제안과 바로가기만 제공한다.

## v1 데이터 연결

현재 DB 스키마 변경 없이 `curated_news.category`, 종목 산업군, 키워드 사전을 이용해 개념과 역량을 추정한다.

향후에는 뉴스 또는 퀴즈에 다음 필드를 추가한다.

- `competency_area`
- `concept_tags[]`
- `difficulty`

이후에는 키워드 추정보다 명시적 태그를 우선 사용한다.

## 서비스 소개

과거 경제 뉴스를 읽고, 그 이후 주가가 오를지 내릴지 맞히는 퀴즈 기반 주식 학습 서비스.  
정답을 맞히면 현금이 쌓이고, 종목을 언락하면 실시간 주가로 모의 투자까지 가능합니다.

## 핵심 플로우

```
시기별 뉴스 읽기 → 상승/하락 예측 → 결과 확인 → 현금 적립 → 모의 투자
```

| 기간 | 보상 |
|------|------|
| 1개월 전 뉴스 정답 | ₩50,000 |
| 3개월 전 뉴스 정답 | ₩100,000 |
| 6개월 전 뉴스 정답 | ₩150,000 |
| 12개월 전 뉴스 정답 | ₩200,000 |

## 기술 스택

| 영역 | 기술 |
